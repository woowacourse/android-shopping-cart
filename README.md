# android-shopping-cart

## 3단계 구현 기능

### 상품 목록 화면

- [x] 장바구니에 담을 상품의 수를 조절할 수 있다.
    - [x] 장바구니 상품 수가 0개일 때: `+` 버튼 노출한다.
    - [x] `+` 클릭 시: 장바구니에 상품 추가 및 수량 조절 버튼으로 전환한다.
    - [x] 상품 수의 변화를 장바구니에 바로 반영한다.
- [x] 상단바에 장바구니에 담겨있는 총 상품의 수량을 노출한다.

### 상품 상세 화면

- [x] 장바구니에 담을 상품 수를 조절할 수 있다.
    - [x] 담기 버튼을 누르면 해당 수량만큼 장바구니에 추가한다.

### 장바구니 화면

- [x] 상품 수를 조절할 수 있다.

### 로컬 데이터베이스 구현(Room)

- [x] 엔티티(Entity) 정의
    - [x] CartEntity: 장바구니에 담긴 상품 정보를 저장 (상품 ID, 수량)

- [x] Dao 정의
    - [x] 장바구니 상품 조회
    - [x] 장바구니 상품 추가/수정/삭제

- [x] Database 정의

## 4단계 구현 기능

### 상품 목록 화면

- [x] 최근 본 상품 목록 표시
    - [x] 최근 본 상품이 존재할 경우, 화면 상단에 최근 본 상품 목록을 노출한다.
    - [x] 최근 본 상품은 최신순으로 최대 10개까지만 노출한다.

### 상품 상세 화면

- [x] 마지막으로 본 상품 표시
    - [x] 화면 내에 가장 마지막으로 본 상품 1개를 노출한다.
    - [x] 마지막 본 상품으로 접근 후 뒤로가기 시 상품목록으로 이동한다.

### 로컬 데이터베이스 구현

- [x] 엔티티(Entity) 정의
    - [x] RecentProductEntity: 최근 본 상품 정보 저장(상품 Id, 시간)

- [x] Dao 정의
    - [x] 최근 본 상품 추가/수정
    - [x] 최근 본 상품 조회

- [ ] 상품 목록의 HTTP Client 구현
