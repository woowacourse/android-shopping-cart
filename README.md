# android-shopping-cart

## 3단계 구현 기능

### 상품 목록 화면

- [ ] 장바구니에 담을 상품의 수를 조절할 수 있다.
    - [x] 장바구니 상품 수가 0개일 때: `+` 버튼 노출한다.
    - [x] `+` 클릭 시: 장바구니에 상품 추가 및 수량 조절 버튼으로 전환한다.
    - [ ] 상품 수의 변화를 장바구니에 바로 반영한다.
- [ ] 상단바에 장바구니에 담겨있는 총 상품의 수량을 노출한다.

### 상품 상세 화면

- [ ] 장바구니에 담을 상품 수를 조절할 수 있다.
    - [ ] 담기 버튼을 누르면 해당 수량만큼 장바구니에 추가한다.

### 장바구니 화면

- [ ] 상품 수를 조절할 수 있다.

### 로컬 데이터베이스 구현(Room)

- [ ] 엔티티(Entity) 정의
    - [ ] CartEntity: 장바구니에 담긴 상품 정보를 저장 (상품 ID, 수량)

- [ ] Dao 정의
    - [ ] 장바구니 상품 조회
    - [ ] 장바구니 상품 추가/수정/삭제

- [ ] Database 정의
