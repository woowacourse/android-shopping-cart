## 상품 목록 페이지 (shopping)
- [x] 초기 진입 시 상품 카드에 `+` 버튼 추가
- [x] `+` 버튼을 누르면 장바구니에 추가됨과 동시에 수량 카운터 컴포넌트가 노출된다.
- [x] 상품 목록의 상품 수가 변화하면 장바구니에도 반영되어야 한다.
- [x] 페이지 상단에 최근 본 상품 목록을 추가한다
  - 상품은 10개까지 확인할 수 있다.
- [x] 최근 본 상품 카드를 누르면 상품 페이지로 이동한다.

## 상품 상세 페이지 (detail)
- [x] 현재 장바구니에 담긴 수량을 수량 카운터 컴포넌트로 표시한다.
- [x] 상품 상세에서 장바구니에 담을 상품의 수를 수량 카운터 컴포넌트를 통해 선택할 수 있다.
- [x] 마지막으로 본 상품 1개를 확인할 수 있다.
  - 마지막으로 본 상품을 선택했을 때는 마지막으로 본 상품 카드가 출력되지 않는다
  - 마지막으로 본 상품 선택 후 뒤로 가기를 누르면 상품 목록 페이지로 이동해야 한다.

## 장바구니 (Cart)

- [x] 장바구니의 상품 수가 변화하면 상품 목록에도 반영되어야 한다.
