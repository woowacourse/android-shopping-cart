# 기능 구현 사항

## 3/4 단계 기능 요구 사항
- [ ] Room, KSP 의존성 추가
- [ ] 로컬 데이터 유지를 위해 Room을 사용한다.
- [ ] 상품 목록의 HTTP Client를 구현한다.
- [ ] MockWebServer를 사용하여 테스트 환경을 구축한다.
- [ ] 네트워크 상태 변경 시스템 이벤트를 감지하여 UI에 반영한다.
- [ ] 상품의 + 버튼을 누르면 장바구니에 상품이 추가된다.
- [ ] 상품 목록에서 장바구니에 담을 상품 수량을 선택할 수 있다.
- [ ] 상품 목록의 상품 수가 변화하면 장바구니에도 반영된다.
- [ ] 장바구니의 상품 수가 변화하면 상품 목록에도 반영된다.
- [ ] 상품 상세에서 장바구니에 담을 상품수량을 선택할 수 있다.
- [ ] 최근 본 상품이 있는 경우, 상품 목록 상단에서 최근 기준 10개까지 볼 수 있다.
- [ ] 가장 마지막으로 본 상품을 상품 상세 페이지에서 볼 수 있다.
- [ ] 마지막으로 본 상품을 선택했을 때는 마지막으로 본 상품이 보이지 않는다.
- [ ] 마지막으로 본 상품 페이지에서 뒤로 가기를 하면 상품 목록으로 이동한다.
- [ ] 앱이 재시작돼도 최근 본 상품 목록과 장바구니 데이터는 유지된다.
