# android-shopping-cart

# 🚀 3단계 - 상태 관리 & 4단계 - HTTP Client

## 구현 기능 목록 (3단계 - 상태 관리)

### Domain

1. 장바구니 상품 수량 관리
- [x] 장바구니에 담긴 상품 수량을 증가시킨다.
- [x] 장바구니에 담긴 상품 수량을 감소시킨다.
- [x] 수량이 0이 되면 장바구니에서 제거한다.
- [x] 장바구니 전체 상품 개수를 계산한다.
- [x] 장바구니 총 금액을 계산한다.
2. 상품 수량 상태 동기화
- [x] 상품 목록에서 변경한 수량을 장바구니 상태에 반영한다.
- [x]장바구니에서 변경한 수량을 상품 목록 상태에 반영한다.
- [x]상품 상세에서 선택한 수량을 장바구니 상태에 반영한다.
- [x]동일 상품의 수량은 모든 화면에서 동일하게 유지한다.
3. 상태 유지
- [x] 시스템에 의해 앱 프로세스가 종료되어도 장바구니 수량 상태를 복원한다.
- [x]화면 회전 등 구성 변경 시에도 현재 수량 상태를 유지한다.

### UI

1. 상품 목록 수량 조절 
- [x] 상품 목록에서 + 버튼을 표시한다.
- [x] 버튼 클릭 시 상품을 장바구니에 추가한다.
- [x] 상품이 장바구니에 담기면 수량 선택 컴포넌트를 표시한다.
- [x] 수량 선택 컴포넌트에서 - / 수량 / + 버튼을 표시한다.
- [x] 수량이 0이 되면 다시 + 버튼만 표시한다.
- [x] 장바구니에 담긴 총 수량을 상단 장바구니 아이콘에 표시한다.
2. 상품 상세 수량 조절
- [x] 상품 상세 화면에서 - / 수량 / + 수량 선택 컴포넌트를 표시한다.
- [x] 사용자가 선택한 수량을 화면에 표시한다.
- [x] 장바구니 담기 버튼 클릭 시 선택한 수량을 장바구니에 반영한다.
3. 장바구니 수량 조절
- [x] 장바구니 화면에서 상품별 수량 선택 컴포넌트를 표시한다.
- [x] 수량 증가/감소 시 상품 수량과 금액을 즉시 갱신한다.
- [x] 수량이 0이 되면 해당 상품을 장바구니에서 제거한다.

## 구현 기능 목록 (4단계 - HTTP Client)
  
### Domain

1. 상품 조회
- [x] HTTP Client를 통해 상품 목록을 조회한다.
- [x] 상품 목록 조회 성공 시 상품 데이터를 반환한다.
- [x] 상품 목록 조회 실패 시 실패 상태를 반환한다.
- [x] 서버 응답 DTO를 상품 도메인 모델로 변환한다.
2. 최근 본 상품 관리
- [x] 상품 상세 화면에 진입한 상품을 최근 본 상품으로 저장한다.
- [x] 최근 본 상품 목록을 최신순으로 조회한다.
- [x] 최근 본 상품은 최대 10개까지만 유지한다.
- [x] 이미 본 상품을 다시 조회하면 기존 기록을 삭제하고 최신 기록으로 갱신한다.
- [x] 최근 본 상품이 없는 경우 빈 목록을 반환한다.
3. 마지막으로 본 상품 관리
- [x] 상품 상세 화면에서 마지막으로 본 상품 1개를 조회한다.
- [x] 현재 보고 있는 상품과 마지막으로 본 상품이 같은지 판단한다.
- [x] 현재 상품과 마지막으로 본 상품이 같으면 마지막으로 본 상품을 반환하지 않는다.
- [x] 마지막으로 본 상품 선택 시 이동할 상품 정보를 제공한다.
4. 장바구니 데이터 유지
- [x] 장바구니 상품을 로컬 DB에 저장한다.
- [x] 장바구니 상품 수량을 로컬 DB에 저장한다.
- [x] 앱 재시작 후 저장된 장바구니 데이터를 복원한다.
- [x] 상품 ID를 기준으로 장바구니 상품 수량을 조회한다.
5. 로컬 데이터 저장
- [x] Room을 사용해 최근 본 상품 데이터를 저장한다.
- [x] Room을 사용해 장바구니 데이터를 저장한다.
- [x] 앱 실행 시 Room에 저장된 최근 본 상품 목록을 불러온다.
- [x] 앱 실행 시 Room에 저장된 장바구니 데이터를 불러온다.
6. 네트워크 상태 관리
- [x] 네트워크 미연결 상태를 감지한다.

### UI
1. 상품 목록 화면
- [x] HTTP Client로 조회한 상품 목록을 화면에 표시한다.
- [x] 상품 목록 조회 중 로딩 UI를 표시한다.
- [x] 상품 목록 조회 실패 시 에러 UI를 표시한다.
2. 최근 본 상품 영역
- [x] 최근 본 상품이 있는 경우 상품 목록 상단에 최근 본 상품 영역을 표시한다.
- [x] 최근 본 상품은 최대 10개까지 표시한다.
- [x] 최근 본 상품을 가로 스크롤 형태로 표시한다.
- [x] 최근 본 상품이 없는 경우 최근 본 상품 영역을 숨긴다.
- [x] 최근 본 상품 카드에는 상품 이미지와 상품명을 표시한다.
- [x] 최근 본 상품 클릭 시 해당 상품 상세 화면으로 이동한다.
3. 상품 상세 화면
- [x] 상품 이미지, 상품명, 가격을 표시한다.
- [x] 상품 수량 선택 컴포넌트를 표시한다.
- [x] 장바구니 담기 버튼을 표시한다.
- [x] 상품 상세 화면 진입 시 해당 상품을 최근 본 상품으로 저장한다. 
4. 상품 상세 - 마지막으로 본 상품 영역
- [x] 마지막으로 본 상품이 있는 경우 상품 상세 화면 하단에 카드 형태로 표시한다.
- [x] 마지막으로 본 상품 카드에 마지막으로 본 상품 라벨을 표시한다.
- [x] 마지막으로 본 상품명을 표시한다.
- [x] 마지막으로 본 상품이 없는 경우 해당 영역을 숨긴다.
- [x] 현재 보고 있는 상품과 마지막으로 본 상품이 같으면 해당 영역을 숨긴다.
- [x] 마지막으로 본 상품 카드 클릭 시 해당 상품 상세 화면으로 이동한다.
- [x] 마지막으로 본 상품을 통해 진입한 상세 화면에서는 마지막으로 본 상품 영역을 표시하지 않는다.
5. 뒤로 가기 처리
- [ ] 일반 상품 상세 화면에서 뒤로 가기 시 이전 화면으로 이동한다.
- [ ] 마지막으로 본 상품을 통해 진입한 상세 화면에서 뒤로 가기 시 상품 목록 화면으로 이동한다.
6. 장바구니 화면
- [x] 앱 재시작 후에도 저장된 장바구니 상품을 화면에 표시한다.
- [x] Room에 저장된 수량을 기준으로 장바구니 상품 수량을 복원한다.
- [x] 장바구니 아이콘의 상품 개수를 저장된 데이터 기준으로 표시한다.
7. 네트워크 상태 UI
- [x] 네트워크가 끊긴 경우 사용자에게 안내 메시지를 표시한다.
