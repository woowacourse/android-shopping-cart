# Android Shopping Cart

## 3단계 구현할 기능 목록

### 1. 상품 목록에서 장바구니에 상품을 담을 수 있다.

- [x] `+` 버튼을 누르면 해당 상품이 장바구니에 1개 추가된다.
- [ ] 상품이 장바구니에 추가되면 `+` 버튼 대신 수량 선택 버튼이 노출된다.
- [ ] 수량 선택 버튼을 통해 상품 수량을 증가시킬 수 있다.
- [ ] 수량이 1개 이상일 때 `-` 버튼을 누르면 상품 수량을 감소시킬 수 있다.
- [ ] 수량이 0개가 되면 해당 상품은 장바구니에서 제거되고, 다시 `+` 버튼이 노출된다.
- [ ] 장바구니에 상품을 추가하거나 삭제하면 장바구니에 담긴 전체 상품 수가 변경된다.

### 2. 상품 상세에서 장바구니에 상품을 담을 수 있다.

- [ ] 수량 선택 버튼을 통해 장바구니에 담을 상품의 수량을 선택할 수 있다.
- [ ] 수량은 1개 이상 선택할 수 있다.
- [ ] 장바구니 담기 버튼을 누르면 선택한 수량만큼 해당 상품이 장바구니에 추가된다.
- [ ] 이미 장바구니에 담긴 상품이라면 기존 수량에 선택한 수량이 더해진다.
- [ ] 상품을 장바구니에 담으면 장바구니에 담긴 전체 상품 수가 변경된다.
- [ ] 상품의 수량이 변경되면 가격도 함께 변경된다.

### 3. 장바구니에서 상품의 수량을 변경할 수 있다.

- [ ] `+` 버튼을 누르면 해당 상품의 수량이 1개 증가한다.
- [ ] `-` 버튼을 누르면 해당 상품의 수량이 1개 감소한다.
- [ ] `-` 버튼을 눌렀을 때 수량이 0개가 될 경우 ‘상품을 삭제할까요?’ 다이얼로그를 노출한다.
    - [ ] 다이얼로그에서 확인 버튼을 누르면 해당 상품이 장바구니에서 제거된다.
    - [ ] 다이얼로그에서 취소 버튼을 누르면 상품은 삭제되지 않고 기존 수량을 유지한다.
- [ ] 상품의 수량이 변경되면 가격도 함께 변경된다.
