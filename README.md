# 기능 구현 사항

## Room
- [x] 장바구니 테이블 정의하기
- [x] 시스템에 의한 프로세스 종료 시에도 현재 수량 상태가 유지되도록 처리한다.

## 수량 카운터 컴포넌트 (QuantityCounter)
- [x] 수량 조절 컴포넌트 만들기

## 상품 목록 페이지 (shopping)
- [x] 초기 진입 시 상품 카드에 `+` 버튼 추가
- [x] `+` 버튼을 누르면 장바구니에 추가됨과 동시에 수량 카운터 컴포넌트가 노출된다.
- [x] 상품 목록의 상품 수가 변화하면 장바구니에도 반영되어야 한다.

## 상품 상세 페이지 (detail)
- [x] 현재 장바구니에 담긴 수량을 수량 카운터 컴포넌트로 표시한다.
- [x] 상품 상세에서 장바구니에 담을 상품의 수를 수량 카운터 컴포넌트를 통해 선택할 수 있다.

## 장바구니 (Cart)
- [] 장바구니에 담긴 상품의 수량 조절을 수량 카운터 컴포넌트를 통해 할 수 있다.
- [ ] 장바구니의 상품 수가 변화하면 상품 목록에도 반영되어야 한다.
