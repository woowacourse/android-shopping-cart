# android-shopping-cart

## 1단계 구현 기능

## 도메인

### 상품(Product)

- [x]  id를 갖는다.
- [x]  이름을 갖는다.
- [x]  가격을 갖는다.
- [x]  이미지 URL을 갖는다. (String)

### 장바구니 아이템 (CartItem)

- [x]  상품(Product)를 갖는다.
- [x]  개수를 갖는다.
- [x]  총 가격을 안다.

### 장바구니(Cart)

- [x]  장바구니 아이템 리스트를 갖는다. → UI 표시용
- [x]  장바구니 아이템을 추가, 삭제 메시지를 보낼 수 있다.

### 상품 리스트 관리 객체(ProductRepository)

- [x]  상품(Product) 리스트를 갖는다.
- [x]  아이디를 통해 상품을 전달한다.

## UI

## 상품 스크린(ProductScreen)

- [x]  메인 탑바를 표시한다. (Shopping, CartIcon)
- [x]  상품 카드들을 표시한다.

### 상품 카드(ProductCard)

- [x]  상품 사진을 표시한다.
- [x]  제목을 표시한다. (오버플로우)
- [x]  가격 정보를 표시한다.

### 메인 탑바(MainTopBar)

- [x]  제목, 우측 아이콘, 클릭 이벤트를 파라미터로 받는다.

## 상품 상세 스크린 (ProductDetailScreen)

- [x] 닫기 버튼이 있는 탑바를 표시한다.
- [x] 상품 이미지를 표시한다.
- [x] 상품 정보 텍스트를 표시한다.
- [x] 장바구니 담기 버튼을 표시한다.

### 장바구니 담기 버튼 (AddCartButton)

- [x]  클릭 이벤트를 파라미터로 받는다.

### 상품 정보 텍스트 (ProductText)

- [x]  상품 이름을 표시한다.
- [x]  상품 가격 정보를 표시한다.

### 닫기 버튼이 있는 탑바 (DismissTopBar)

- [x]  닫기 버튼 클릭 이벤트를 파라미터로 받는다.
- [x]  닫기 버튼을 표시한다.

## 장바구니 스크린 (CartScreen)

- [x]  카트 아이템 카드를 표시한다.
- [x]  뒤로가기 버튼이 있는 탑바를 표시한다.

### 카트 아이템 카드 (CartItemCard)

- [x]  상품 이름, 가격, 이미지를 표시한다.
- [x]  닫기 버튼을 표시한다.
- [x]  닫기 버튼 클릭 이벤트를 파라미터로 받는다.

### 뒤로가기 버튼이 있는 탑바 (NavigateUpTopBar)

- [x]  뒤로가기 버튼을 표시한다.
- [x]  타이틀을 표시한다.
- [x]  뒤로가기 클릭 이벤트와 타이틀을 파라미터로 받는다.

## 화면 연결

- [x] 상품 리스트 화면 도메인 연결
- [x] 상품 디테일 화면 도메인 연결
- [x] 장바구니 화면 도메인 연결
- [x] 화면 이동 로직 구현

## 2단계 구현 기능

- [x] 상품 스크린 더보기 버튼 추가
- [x] 카트 스크린 페이지네이션 UI 추가
- [x] 카트 페이지네이션 기능 추가 (5개당 한 페이지)
- [x] 상품 더보기 기능 추가 (20개씩 불러오는 기능)


## 3단계 구현 기능
- [x] 탑바에 장바구니에 포함된 상품의 종류 개수를 표시한다. (0개라면 표시하지 않는다.)
- [x] 상품 카드에 + 버튼을 추가한다.
  - [x] +버튼을 누르면 개수와 +, - 버튼이 표시된다.
  - [x] 장바구니에 알맞은 개수가 추가된다.
- [x] 상품 상세 스크린에 개수를 선택하여 장바구니에 추가할 수 있다.
  - [x] +, - 버튼과 개수가 표시된다.
  - [x] 개수에 따른 알맞은 가격이 표시된다.
- [x] 카트에서 개수를 조정할 수 있다.
  - [x] +, - 버튼과 개수가 표시된다.
  - [x] 개수에 따른 알맞은 가격이 표시된다.
- [x] 시스템에 의한 프로세스 종료 시에도 현재 수량 상태가 유지되는 기능 추가


## 4단계 구현 기능
- [x] 최근 본 상품 카드를 구현한다.
- [x] 상품 스크린 상단에 최근 본 상품을 표시한다.
  - [x] 상품 이미지, 상품 이름이 표시된다.
  - [x] 기존 스크롤과 같은 스크롤을 사용한다.
  - [ ] 최대 10개까지 확인할 수 있다.
- [x] 마지막으로 본 상품 카드 컴포넌트를 구현한다.
- [x] 상품 상세 스크린에서 마지막으로 본 상품을 표시한다.
  - [x] 상품 이름을 표시한다.
  - [x] 마지막으로 본 상품과 같은 상품에서는 보이지 않는다.
  - [x] 마지막으로 본 상품 페이지에서 뒤로가기를 누르면 상품 스크린으로 이동한다.
- [x] 최근 본 상품을 저장해둔다. (앱이 재시작되어도 유지된다.)
- [x] 상품 목록의 HTTP Client를 구현한다.
- [ ] MockWebServer를 이용하여 테스트를 진행한다.
- [ ] 네트워크 상태 변경 시스템 이벤트를 감지하여 UI에 반영한다.
